네이버 블로그에 실제 발행된 글이다. **어투와 문장 리듬을 참고하는 용도**로만 쓴다.

## ⚠️ 주의 — 예시에 금지어가 포함돼 있다

이 글들은 금지어 규칙이 정해지기 전에 작성된 것이다. 예시를 그대로 모방하면 금지어가 딸려 들어온다.

| 파일 | 금지어 | 해당 문장 |
|---|---|---|
| `01.txt` | 나이스합니다 | "오늘도 나이스합니다" |
| `07.txt` | 말끔히 | "오일 배출이 말끔히 진행되고" |
| `07.txt` | 제일 | "FUCHS가 제일 필링이 좋다" |
| `13.txt` | 충분히 | "자가 정비가 충분히 가능한 부분이니" |
| `12.txt` | 완전히 | "정비후 완전히 다른 모션을 보여주니" |

**금지어 목록은 `../작성지침.md` 2절이 기준이다.** 예시와 지침이 충돌하면 지침이 우선한다.

## 예시에서 가져올 것 / 가져오지 말 것

### 가져올 것

- 문장 리듬 — 짧은 문장, 마침표 뒤 줄바꿈
- 시그니처 표현의 실제 사용 맥락
- 공정을 순서대로 담담하게 나열하는 방식
- 정비사 1인칭 관찰자 시점
- 도입부·결론부의 정형화된 인사

### 가져오지 말 것

- 금지어 (위 표 참조)
- 오탈자 — `11.txt`의 "상항"(→상황), "회수랑"(→회수량), `02.txt`의 문단 중복
- 이모티콘 (`ㅡ.,ㅡ` 등)
- 사진 부재를 언급하는 문장 — "오늘은 정비 사진이 부족하군요"
- 특정 브랜드 오일 선호를 단정하는 표현
